# Agent Task Notify 独立程序升级设计

日期：2026-08-28。状态：方向已确认，书面设计待审阅；不是已发布功能说明。

## 1. 给使用者的承诺

在原仓库升级，不创建另一个项目。目标是提供 Windows 和 macOS 对应的通知小工具：用户让本地 Agent 协助下载、核对版本和安装，自己在本机填写推送凭据并完成必要授权。通知工具本身不要求另装 PowerShell、Node.js、Python 或 Go；Agent 自身的依赖不在这个承诺内。

保留六种 Agent、Bark/ntfy、各自通知图标以及可调的门槛、铃声和提醒时长。不擅自升级已安装的旧版，不读取旧设备密钥，不覆盖现用 Hook。Mac 初期仅按实际证据标注实验性支持，不以编译通过冒充完整兼容。

本次先更新软件仓库。宣传视频是软件交付之后的独立后续事项，不进入本次实现或验收范围。

## 2. 为什么选独立程序

| 方案 | 优点 | 代价 | 本次选择 |
| --- | --- | --- | --- |
| 继续 PowerShell 并补 Mac 平台层 | 复用最多、改动较小 | 使用者仍要安装运行环境 | 保留旧版作为过渡，不作为新入口 |
| 改为 Node.js 脚本 | 部分 Agent 环境可复用 Node | 不能假设所有桌面 Agent 都提供可调用的 Node | 不采用 |
| Go 编译为平台程序 | 通知工具免装语言环境，两平台共享主要逻辑 | 需要移植、安全存储和发布验证 | 采用；先验证难点，再全面移植 |

Go 运行时随程序编译，不等于没有操作系统依赖。macOS 安全接口需要原生桥接；在 Mac CI 构建，不承诺在 Windows 上直接完成全部跨编译。

## 3. 范围与不做的事

范围：Windows x64、Mac Intel/Apple Silicon；六个现有来源；两种现有推送通道；命令行安装、配置、检查、预览和卸载；平台发行包、测试及中英文说明。

不新增 GUI、手机 App、云推送代理、账号系统、遥测、付费订阅、Linux 支持或常驻开机服务。不借这次移植增加跨整个项目累计计时，也不承诺捕获所有权限等待。不中途自动更新正在执行任务的安装版本，不发历史补提醒。

仅保留原生事件契约已确认的行为。WorkBuddy 桌面仍为实验性；各 Agent 的自动接入必须明确区分“代码实现”“契约测试”“真实宿主测试”。

## 4. 先验证的三个门槛

正式移植前，先在隔离环境验证最小原生程序：

1. **能独立运行**：发行包解压后能运行检查命令；测试进程的可执行文件搜索路径中不提供 PowerShell/Node/Python/Go；中文、空格路径正常。
2. **能安全保管凭据**：Windows 原生用户级保护、Mac 原生 Keychain 均完成合成数据写入/读取/失败测试；未授权或锁定时明确失败，不回退明文，不让后台进程弹出无限等待的授权窗口。
3. **能在 Hook 结束后发送**：Hook 的标准输出及时关闭，工作进程不占住宿主管道；对本地假推送服务完成异步发送、重试及续响；宿主实际终止进程树的行为另列人工验收。

失败时停止该平台的全面移植并报告原因。不能为通过测试降低凭据保护、关闭系统安全检查，或偷偷改回“用户必须装 PowerShell”的方案。

## 5. 模块边界

| 模块 | 职责 | 不负责 |
| --- | --- | --- |
| `cmd/agent-task-notify` | 命令解析、退出码、安全输出 | 业务状态判断 |
| `internal/adapters` | 六种输入转为统一事件、生成中性 Hook 响应 | 读取任务正文或推送凭据 |
| `internal/core` | 计时、门槛、幂等、生成通知任务 | 系统 API 与 HTTP |
| `internal/store` | 带版本的状态、原子替换、跨进程锁 | 系统凭据解密 |
| `internal/secrets` | 凭据/备份的保护与读取 | 将凭据输出到终端或日志 |
| `internal/worker` | 后台进程、发送状态、有限重试、续响 | 启动守护服务或无限恢复 |
| `internal/providers` | Bark/ntfy 请求白名单、响应验证 | 根据任务原文编写通知 |
| `internal/install` | 合并/卸载自有 Hook、加密备份、安装收据 | 覆盖其他工具配置或自动信任插件 |
| 发行资源与 Skill | 默认值、品牌映射、平台选择、安装说明 | 依靠模型记忆计时或常驻监听 |

默认配置和图标映射保留单一数据源，打包时嵌入核心并校验一致性。OpenCode 保留由其宿主加载的薄 JS 桥接层，仅调用原生工具；不另要求安装系统 Node。

## 6. 接口与事件

用户入口：`install`、`configure`、`doctor`、`preview`、`uninstall`、`version`。内部入口：`hook`、`worker`。显式选择 `--agent`；内部 worker 只接受校验后的任务键，不接受任意待执行命令。

统一事件字段沿用 `agentId`、`sessionId`、`nativeRunId`、`eventType`、`reason`、`isChild`。原生事件映射延续现有契约：Codex 开始/停止、Claude Code 开始/停止/失败、Cursor 开始及停止状态、Gemini CLI BeforeAgent/AfterAgent、OpenCode 的现有桥接事件、WorkBuddy 的已记录实验性事件。

严格验证 UTF-8、JSON 对象及必需字段；单个 Hook 输入限制为 4 MiB，超限以脱敏错误计数并返回中性响应。忽略未知事件及子 Agent 事件。输入不得当作命令执行；原始输入、任务正文、原生会话标识不落盘。持久状态使用散列键。

没有原生运行 ID 的来源仍可能遇到延迟 Stop 无法精确归属的问题。保留并记录此边界，不声称移植语言本身能消除歧义。

Hook 错误遵循当前宿主所需的中性响应，不因通知失败阻止 Agent。用户主动执行的配置/预览失败应返回非零退出码与脱敏错误码。stdout 只包含约定输出；不混入调试日志或密钥。

## 7. 计时、重试与声音

- 默认单次运行满 1800 秒触发提醒；满 3600 秒使用长任务档位。重复开始不重置同一运行，重复终止不创建第二份主任务。
- 默认 Bark 目标提醒长度为 45/60 秒，铃声 `alarm`；配置项继续可调。连续模式维持现有 30–60 秒范围，普通单次模式按声音本身播放。
- 续响基于首次成功发送后的相对时间调度；目标长度不是 iOS 的精确计时保证。手机系统/网络可能造成延迟，可能在历史中产生第二条提醒。
- ntfy 保留可调优先级，声音由手机控制，不宣传精确 45/60 秒；禁止把 Bark 的 `call` 映射为 ntfy 的真实电话参数。
- 主推送最多 5 次尝试，追加等待 5/15/30/60 秒。仅对明确可重试的传输/业务错误重试，续响保持一次发送。
- HTTP 成功不等于业务成功；验证 Bark 业务码及 ntfy 消息回执。服务接受不等于手机已收到，不显示虚假的“手机送达”。
- 发送后崩溃可能产生不确定结果；记录脱敏状态，不自动重放不确定发送，不承诺恰好一次、断网必达或电脑关机后继续通知。
- 任务创建时冻结设置和图标，重试与续响不读取中途修改的显示配置。

本次不改变原有 `needs_attention` 能力边界。当前六个原生适配器均不保证发出该事件，不将“所有需要用户配合的时刻必提醒”作为宣传文案。

## 8. 安全存储与文件

新原生安装使用独立运行数据目录，避免直接消费旧脚本状态：Windows 用户本地应用数据下 `AgentTaskNotifyNative`；Mac 用户 `Library/Application Support/AgentTaskNotifyNative`。允许显式选定用户拥有的目录，但拒绝与源码目录、已知旧版运行目录或其他用户目录混用。

Windows 的保护层使用当前用户 DPAPI 原生接口。Mac 使用 Keychain 保存随机数据加密密钥，凭据和安装前原始配置备份通过标准库 AES-GCM 加密为带版本、用途及安装实例标识的封套。密钥不随 staging 目录变化而改变，配置事务移动封套后仍可读取。禁止自行设计加密算法或把密钥和密文同放普通文件。

Mac 原生桥接首选评估 `keybase/go-keychain`，实现前冻结并审查依赖版本/许可。Keychain 不启用跨设备同步；前台配置可请求必要授权，后台读取不得弹出交互窗口。锁定/无权限/损坏应安全失败。若库无法实现这些约束，回到第 4 节停止条件，不使用带密钥命令行参数的 `security` 调用替代。

数据目录采用平台适当的用户权限；临时文件与目标文件同目录、限制权限。跨进程锁使用 Windows/Unix 对应原语，退出后能释放，不照搬 Windows FileShare 假设。加密备份与收据均不进入 Git、发行包或诊断报告。

HTTP 保留 HTTPS、端点验证、不自动跟随重定向、明确超时和发送字段白名单；本地回环服务仅用于隔离验证。完整 URL、令牌、响应正文与底层异常文本不进入日志。

## 9. 安装与回退

下载明确版本的官方仓库发行包，校验其来源/平台/散列及提供的构建证明；不执行 `curl | shell`。校验散列仅能发现内容不符，不能单独证明发布者身份。安装器不擅自安装系统运行时、不申请管理员权限、不更改系统安全策略。

安装前显示目标 Agent 和将修改的文件，验证可执行文件与现有配置；先保存受保护的原始配置备份，再合并仅属本工具的 Hook。保留未知字段、其他 Hook 和权限；重新读取确认成功后再提交收据。文件有外部改动时不覆盖。卸载只移除收据确认的自有项，不整份恢复旧配置，不递归删除用户目录。

原有安装与新原生版二选一。遇到已知旧版或无法判定归属的 Hook，停止并给出本地处理指引，不重复注册。第一版不自动迁移旧凭据/活动运行；用户选择切换时在本地重新配置，并保留旧版回退路径。安装收据存在不等于宿主已经加载。

各 Agent 的路径、命令引用、插件清单沿用并复核公开契约；未确认的路径或宿主版本不能自动写入。Codex 原 `notify` 配置不覆盖，Hook 信任由宿主/用户完成。WorkBuddy 发布自包含实验包，不猜测桌面配置文件。

## 10. 成熟组件与资源

继续使用 Bark/ntfy，不开发新的推送服务。Go 标准库承担 JSON、HTTP、时间与通用加密；必要的系统桥接采用审查过的依赖。Shoutrrr 可作参考，但现有公开 Bark 参数不足以证明完整覆盖续响/关键警报，当前不直接替换发送层。

六个 Agent 的名称/图标映射与来源说明保留，包括 WorkBuddy；默认图标可覆盖或关闭。图片是第三方通知装饰，不代表修改 Bark/ntfy 的应用图标，也不代表官方背书。第三方品牌素材不自动归入本项目 MIT 许可。

## 11. 构建、测试与分发门槛

Go 工具链及所有依赖固定可审计版本。构建移除本机路径，发行包采用明确文件清单，不包含运行数据、凭据、真实日志或私有文档。原 Windows PowerShell 测试在迁移期继续保留，作为行为回归参照。

| 层次 | 验证内容 | 可证明的范围 |
| --- | --- | --- |
| 纯逻辑 | 六源映射、计时阈值、重复/乱序事件、配置、声音/图标快照 | 规则与契约 |
| 隔离进程 | UTF-8/中文路径、并发锁、后台生存、管道关闭、有限重试 | 平台进程与文件行为 |
| 系统安全 | 合成凭据、加密备份、拒绝授权、权限/损坏失败 | 测试账户下的系统集成 |
| 安装事务 | 原配置保护、重复安装、外部编辑、故障回退、卸载归属 | 合成宿主配置安全 |
| 发行包 | 解压即运行、缺少额外语言环境、资源/版本、隐私清单 | 发布产物可启动 |
| 真人验收 | 真实 Agent 触发、首次授权、锁屏手机到达及声音 | 被测试的具体组合 |

目标 CI 覆盖 Windows x64、Mac Intel/Apple Silicon。macOS 15 与 macOS 26 分别验证，不将 CI 中未执行的平台版本写为已测试。原生 Keychain 测试在独立临时 Keychain/专用测试命名空间运行；不读取用户现有 Keychain。全部自动发送只面向本地假服务，不使用真实设备密钥。

公开仓库可使用 GitHub 标准 Mac runner；自动化不能替代真人桌面与手机验收。每个发行版本提供明确矩阵，标明构建、契约、宿主和手机的证据，不把旧版历史实测借给新版。

Mac 的 Developer ID/公证与运行测试是独立事项。没有获授权的签名身份时，产物只能明确标为未公证的候选测试包；普通安装入口不自动启用此包，不写移除 quarantine 或关闭 Gatekeeper 的脚本。面向普通用户的便捷 Mac 发行入口须通过安全分发与首次启动验收，否则保持实验性并说明缺口。不得未经授权购买会员、证书或付费构建服务。

## 12. 实施顺序与停止条件

1. 固定现有契约与合成测试；先验证第 4 节的原生运行、安全存储、后台进程。
2. 门槛通过后移植共享核心和六个适配器，保留配置/图标规则及安全边界。
3. 完成安全安装/卸载、Skill 与两平台包；运行回归和发行物测试。
4. 更新原仓库文档与兼容性矩阵，发布与证据相符的版本；不改任何现用安装。

遇到无授权的费用/账户、Mac 安全分发不能落实、Keychain 需要不安全降级、宿主契约冲突或无法安全迁移时，暂停受影响部分并报告。其他可独立验证的工作可继续；不以缺少 Mac 为借口虚报验收，也不无限尝试同一阻塞。

## 13. 本次成功标准

- 原仓库拥有可复现的原生源代码、平台包与自动测试，用户安装通知工具不需要额外语言环境。
- 六来源、两通道、图标、可调默认配置及旧版关键安全行为没有遗漏。
- 原有 Windows 安装不被开发、测试或发布过程触碰。
- 公开文档准确区分实验性/已测试；Mac 未通过的安全分发或真人验收不被隐瞒。
- 没有泄露密钥、私人任务内容或私人路径，没有未经同意的付费操作。
