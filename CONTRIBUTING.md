# Contributing

Use PowerShell 7.4+ and Node. Run `pwsh -NoProfile -File tests/Run.Tests.ps1`, then `pwsh -NoProfile -File scripts/Test-Release.ps1`. Do not add credentials, device endpoints, real task IDs, logs, screenshots, or machine-specific paths. Keep tests offline and use synthetic data.

For bugs, use the issue template and sanitise all reports. Changes to host hooks require documented source evidence and must preserve explicit user review/trust boundaries.
