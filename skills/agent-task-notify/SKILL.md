# Agent Task Notify

Native candidate `0.2.0-rc.1` supports Windows x64 and experimental Mac Intel/Apple Silicon. The notifier needs no separately installed PowerShell, Node, Python or Go; a host's own runtime/command shell is a separate prerequisite. This Skill assists a capable local Agent; importing it or reading the repository neither installs software nor enables a daemon or notifications.

Use the requested mode only: inspection, dry preview and removal never require installing/configuring first. In a downloaded package, the root `INSTALL.md` and `INSTALL.zh-CN.md` contain offline setup instructions; do not assume a source checkout or `scripts/` exists. Detailed [candidate configuration](https://github.com/kj858bp8g2-ship-it/agent-task-notify/blob/v0.2.0-rc.1/docs/native-configuration.md) and [compatibility/evidence](https://github.com/kj858bp8g2-ship-it/agent-task-notify/blob/v0.2.0-rc.1/docs/native-compatibility.md) are optional online references.

- **Before setup:** confirm OS/architecture and reviewed same-repository source/release provenance; compare the exact archive SHA256SUMS before extraction into a new owned directory. Hashes are not publisher authentication. Mac is UNSIGNED and NOT NOTARIZED: stop ordinary auto-install, explain the experimental developer route and missing first-launch/Keychain/Gatekeeper evidence. Do not remove quarantine, bypass Gatekeeper or seek administrator access. Proceed only within explicit experimental authorization and OS policy.
- **Data and host:** use the absolute packaged executable (`agent-task-notify.exe` on Windows, `agent-task-notify` on Mac). Keep an independent writable, owned `--data-directory ABS_DATA` outside package/source/legacy data. This flag overrides `ATN_DATA_DIRECTORY`, then Windows LocalApplicationData/AgentTaskNotifyNative or Mac Library/Application Support/AgentTaskNotifyNative. Its parent must already exist. Keep that exact data path across actions. Confirm the host shell and trust workflow; your current terminal does not prove the host shell. Identify existing legacy/plugin registrations without reading credentials; there is no automatic migration or complete duplicate-route detector.
- **Inspect:** `agent-task-notify version`, then `agent-task-notify doctor --data-directory ABS_DATA`. Doctor reads settings and envelope presence, not credential authentication, unlocked Keychain, host loading or phone delivery. Do not prompt for Keychain authorization during doctor or dry preview.
- **Configure:** `agent-task-notify configure --provider bark --data-directory ABS_DATA`, or select `ntfy`. User enters the endpoint/token only at the local hidden terminal prompt, never in chat, command arguments or a copied transcript. Optional `--settings-file ABS_JSON` is a local nonsecret settings patch. Nonterminal secret input requires explicit `--credential-stdin` from an authorized local source; do not collect it yourself in chat. Only explicit configuration or foreground Vault operations (including authorized applied installation/removal) can create/authorize Mac Keychain storage; background/readonly credential reads never prompt or create keys. Bark is for iOS; ntfy/Android is experimental. The service receives its credential and generic content; DPAPI/Keychain protects local storage, not end-to-end push encryption. Verify ntfy topic ACLs; random names or a token alone do not prove privacy. Unauthenticated opt-in accepts exposure.
- **Preview:** `agent-task-notify preview --agent ID --data-directory ABS_DATA` sends nothing. Add `--send` only for the user's explicit optional audible test. Queued or sender-accepted is not phone arrival. Enabled lifecycle hooks also send automatically after thresholds; preview is not the only sending path.
- **Install:** first show `agent-task-notify install --agent ID --command-shell SHELL --data-directory ABS_DATA`; review the printed target before repeating with authorized `--apply`. SHELL is verified `cmd`, `powershell` or `posix`, not a guess. Optional `--config-path ABS_FILE` selects a verified host config. Existing owned host/plugin parent is required; the installer does not create/repair it. Empty/whitespace/malformed existing JSON must be handled explicitly, never silently replaced. Preserve unknown hooks/settings and Codex `notify`; leave trust to the host/user. OpenCode's `opencode.json` is a locator; the actual target is sibling `plugins/agent-task-notify.js`, using packaged integrations and direct native spawn. Receipt ownership does not prove no alternative plugin registration.
- **WorkBuddy:** `workbuddy` is a manually imported, self-contained experimental subpackage with its own matching runtime binary and Bash launcher. Do not invoke automatic `install` for it or guess desktop settings. Configure its binary copy using the same data path; pass `ATN_DATA_DIRECTORY` to the host when nondefault. Verify the host's plugin workflow and supplied `CODEBUDDY_PLUGIN_ROOT` (fallback `CLAUDE_PLUGIN_ROOT`); desktop loading/cancellation remain untested.
- **Remove:** preview `agent-task-notify uninstall --agent ID --data-directory ABS_DATA`, then use `--apply` only after review. Keep the original package until exact-owned uninstall finishes: missing package identity or edited-owned entries cause refusal. Never restore the entire stale backup or delete user/data folders/Keychain items. Remove WorkBuddy manually through the verified host. If returning to legacy, first disable/remove the native route, then explicitly re-enable one reviewed legacy route with its own data; never blindly restore or auto-upgrade.

Six IDs: `codex`, `claude-code`, `cursor`, `gemini-cli`, `opencode`, `workbuddy`. Each has embedded remote icon metadata (Codex/ChatGPT, Claude, Cursor, Gemini, OpenCode, WorkBuddy); artwork decorates notifications, not the app/system small icon. Remote artwork can change; its reference grants no brand license.

Defaults are tunable: 1800-second minimum, 3600-second long threshold, Bark 45/60-second targets and `alarm`. Continuous Bark uses a second notification for extension; timing is approximate. ntfy sound is phone-controlled, with no Call/X-Call or real telephone call. No adapter guarantees `needs_attention`; without a native run ID, delayed Stop can be ambiguous. Retries are bounded (five main attempts, waits 5/15/30/60 seconds; extension once), not an offline/reboot/service guarantee. Settings/icons freeze per job. Do not promise replay after crash, exactly-once delivery, every attention moment, or phone arrival. No extra telemetry is added.

Legacy Windows script/plugin assistance remains available only when requested through the [legacy instructions](https://github.com/kj858bp8g2-ship-it/agent-task-notify/blob/v0.2.0-rc.1/README.md#legacy-windows-route); it is not the native default and is not included as a script dependency in this package.
